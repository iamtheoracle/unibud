# UNIBUD HOME & DISCOVER SPECIFICATION

> Home is the centre of every student's university life.
> It should feel alive, personal, organized, and motivating — never like a dashboard.
> Discover is one intelligent exploration system, not multiple disconnected pages.

---

## 1. HOME SCREEN PRINCIPLES

### 1.1 Core Philosophy
- Never feels like a dashboard or enterprise portal.
- Feels alive, personal, organized, and motivating.
- Students immediately know what matters today.
- New opportunities are discovered naturally.
- No two Home screens are identical — every student's journey is unique.

### 1.2 Personalization Sources
Home is personalized using (with permission):
- Student's profile, university, programme, department, academic level.
- Interests, goals, previous activity.
- Timetable, assignments, examinations, meetings.
- Study streak, learning progress, weekly goals.
- Preferences and accessibility settings.

### 1.3 Three-Zone Hierarchy
Every Home screen follows the three-zone information hierarchy:

| Zone | Content |
|---|---|
| **Zone 1: Context & Status** | Greeting, daily motivation, study streak, GPA/CGPA progress, attendance summary, today's timetable |
| **Zone 2: Primary Content** | Today's lectures, upcoming assignments, examinations, meetings, "Continue Where You Left Off", personalized recommendations |
| **Zone 3: Supporting** | Recent learning activity, campus feed preview, announcements, wellbeing widgets, discovery preview |

---

## 2. HOME SCREEN ELEMENTS

### 2.1 Personalized Greeting
- Based on student's local time (Good morning/afternoon/evening).
- Uses preferred name.
- Followed by a daily motivation or encouragement (rotates, contextually relevant).

### 2.2 Today's Summary
- Today's timetable and upcoming lectures.
- Assignments due.
- Examinations upcoming.
- Meetings or scheduled events.
- Attendance summary (where available).
- GPA/CGPA progress (where available, optional).

### 2.3 Study Streak & Goals
- Current study streak with visual day grid.
- Weekly goals progress.
- Recent learning activity.
- Celebration of milestones (not unhealthy competition).

### 2.4 Continue Where You Left Off
One intelligent system that remembers:
- Unfinished lessons.
- Open notes.
- Incomplete assignments.
- Active StudyBuddy conversations.
- Research sessions.
- Projects.
- Uploaded files.
- Reading progress.

Students resume instantly from any device.

### 2.5 Personalized Recommendations
- Based on interests, academic level, and goals.
- Improves continuously using learning behavior (with permission).
- Never recommends random content to increase activity.
- Every recommendation has clear educational or personal value.

## 6. NOTIFICATION PRIORITY SYSTEM

One intelligent notification system that understands priority.

### 6.1 Notification Categories

| Category | Examples | Override |
|---|---|---|
| **Critical** | Emergency alerts, security events, account actions | Yes (always delivered) |
| **Academic** | Assignment due, exam reminder, grade posted, class cancellation | No |
| **Personal** | Direct messages, mentions, connection requests | No |
| **Community** | Community posts, group mentions, event updates | No |
| **General** | Announcements, recommendations, platform updates | No |

### 6.2 Rules
- Deliver only relevant notifications.
- Users control preferences for every category.
- Critical/security alerts override preferences.
- Notifications intelligently group similar events.
- Reduce unnecessary interruptions.
- Users control every category independently.

## 11. OFFLINE & PERFORMANCE

### 11.1 Offline Access
Important Home information available offline:
- Timetable, calendar, saved notes.
- Downloaded resources, reminders.
- Upcoming deadlines.
- Recent StudyBuddy conversations.

Changes synchronize automatically when connectivity returns — no duplicate data.

### 11.2 Performance Requirements
- Every interaction feels immediate.
- Pull-to-refresh is smooth.
- Widgets animate naturally.
- Navigation remains fast on slower devices.
- Skeleton loading, intelligent caching, and background sync make the platform responsive under all network conditions.
- Reduce unnecessary animations on lower-powered devices.
