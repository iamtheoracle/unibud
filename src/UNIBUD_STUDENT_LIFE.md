# UNIBUD STUDENT LIFE ECOSYSTEM SPECIFICATION

> UNIBUD is the student's everyday companion — not just a study application.
> One unified Student Life ecosystem where every service connects naturally with academics, profiles, communities, calendar, and notifications.

## 2. MARKETPLACE

### 2.1 Philosophy
Premium, trustworthy, organized, and modern. Prioritizes safety and student verification. Never creates fake listings, reviews, or ratings.

### 2.2 Sellers
Verified students, lecturers, alumni, organizations, and universities.

### 2.3 Listing Categories

| Category | Examples |
|---|---|
| **Textbooks** | Course textbooks, study materials |
| **Lecture Notes** | Study notes and summaries |
| **Past Questions** | Previous exam papers |
| **Electronics** | Laptops, phones, accessories |
| **Furniture** | Desks, chairs, beds |
| **Accommodation** | Housing listings (links to Accommodation Centre) |
| **Clothing** | Fashion and university apparel |
| **Calculators** | Scientific and graphing calculators |
| **Laboratory Equipment** | Lab gear and supplies |
| **Vehicles** | Bicycles, motorcycles, cars |
| **Event Tickets** | Concert, event, and sports tickets |
| **Tutoring** | Academic tutoring services |
| **Graphic Design** | Design services |
| **Programming** | Development services |
| **Photography** | Photography services |
| **Printing** | Printing and binding services |
| **Editing** | Proofreading and editing services |
| **Freelance Services** | General freelance work |
| **Campus Businesses** | Student-run businesses |
| **Future Services** | Extensible to new categories |

### 2.4 Listing Fields

| Field | Description |
|---|---|
| **High-quality Images** | Multiple images per listing |
| **Videos** | Video showcasing |
| **Description** | Detailed description |
| **Category** | Listing category |
| **Pricing** | Price in local currency |
| **Availability** | In stock, reserved, sold |
| **Condition** | New, like new, good, fair |
| **Location** | Campus, city, online |
| **University** | Associated institution |
| **Department** | Associated department (if relevant) |
| **Seller Verification** | Verified student/organization badge |
| **Ratings** | Seller rating from past transactions |
| **Reviews** | Buyer reviews |
| **Favourites** | Save listings |
| **Bookmarks** | Bookmark for later |
| **Sharing** | Share listing link |
| **Reporting** | Report inappropriate listings |
| **Moderation History** | Internal moderation record |
| **Intelligent Recommendations** | Related listing suggestions |

### 2.5 Safety Systems

| Feature | Description |
|---|---|
| **Scam Detection** | Automatic scam pattern detection |
| **Suspicious Behaviour Monitoring** | Flag unusual activity |
| **Verified Student Badges** | Confirm student status |
| **Verified Organizations** | Confirm org status |
| **Trusted Sellers** | Reputation-based trust indicators |
| **Safe Meeting Recommendations** | Suggest on-campus or public meeting points |
| **Reporting Tools** | Easy reporting of issues |
| **Moderation Workflows** | Reviewed by moderators |
| **Fraud Prevention** | Pattern-based fraud detection |

### 2.6 Rules
- Never expose unnecessary personal information.
- Encourage safe transactions.
- Empty state with onboarding guidance when no listings exist.
- Universities and verified organizations can publish official listings.

## 11. CROSS-MODULE INTEGRATION

Every Student Life feature integrates with:

| Module | Integration |
|---|---|
| **Calendar** | Deadlines, events, payment reminders |
| **Discover** | Recommendations surface in Discover |
| **Notifications** | Deadline and update alerts |
| **Messaging** | Inquire about listings, communicate with sellers/landlords |
| **Communities** | Discuss services and opportunities |
| **Profiles** | Verified status, reputation |
| **StudyBuddy** | Career guidance, application help |

### Rules
- Students move naturally between learning, campus life, and personal development.
- No feeling of using multiple disconnected applications.
- Every service is globally adaptable (local languages, currencies, education systems, regulations, locally available services).
